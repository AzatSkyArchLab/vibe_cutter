# vibe_cutter

Простой видеоредактор в браузере в духе страницы Edit из DaVinci Resolve: склеить и нарезать клипы, отрендерить под YouTube или Kinescope. Работает в Google Chrome на Mac, ничего ставить не нужно.

## Возможности

- Импорт MP4/MOV с iPhone (HEVC, HDR, переменная частота кадров), с камеры и из OBS — перетаскиванием или кнопкой.
- Дорожки V1…Vn и A1…An, связанные видео и звук, пустоты между клипами. ⌘/Alt + колесо — масштаб таймлайна вокруг курсора.
- Резы, удаление с пустотой и со сдвигом, подрезка краёв, перемещение между дорожками, привязка к точкам монтажа, In/Out.
- Титры как в Resolve: «Текст по центру», «Подпись слева внизу» (имя + должность, нижняя треть) и «Подпись внизу по центру». Это клипы на видеодорожке — их режут, двигают и растягивают как обычные клипы; оформление в инспекторе: шрифт, размер, цвет, тень, обводка, плашка или полоса, сдвиг, появление и исчезновение. Размер считается от короткой стороны кадра, поэтому в вертикальном видео надпись такая же, как в горизонтальном.
- Таймлайн 1080p и 4K, горизонтальный 16:9 и вертикальный 9:16; кадр другой пропорции вписывается или заполняет кадр.
- Рендер на видеокарте через WebCodecs: H.264 или HEVC, AAC 48 кГц, MP4 с Fast Start, Rec.709 SDR. Файл пишется сразу на диск.
- Сжатие любого видео («Рендер → Сжать файл»): до нужного размера файла (битрейт и разрешение подбираются сами, при промахе кодера — второй проход), по качеству или просто смена формата MOV → MP4 без перекодирования. HDR переводится в SDR, звук остаётся синхронным, у файла Fast Start.
- Проект сохраняется в файл `.vcut` (⌘S) — к монтажу можно вернуться в любой момент: «Проект → Открыть» (⌘O), недавние проекты или просто перетащить `.vcut` в окно. После первого сохранения каждое изменение само записывается в этот файл; запись атомарная, оборванная запись не портит проект.
- Файл проекта хранит монтаж и описание исходников, само видео в него не входит (как `.drp` в Resolve). При открытии исходники находятся по имени и размеру; если видео переехали — «Указать папку…» в Media Pool.
- Дополнительно рабочая сессия автосохраняется в браузере: после перезагрузки или сбоя вкладки монтаж восстанавливается.

## Горячие клавиши (как в Resolve)

| Клавиши | Действие |
|---|---|
| Пробел, K, L | пуск / стоп / пуск |
| ← → (⇧ — секунда) | кадр назад / вперёд |
| ↑ ↓ | предыдущая / следующая точка монтажа |
| I, O, ⌥X | In, Out, сбросить |
| A, B | выделение, лезвие |
| ⌘B | разрезать под плейхедом |
| ⌫ / ⇧⌫ или Del | удалить с пустотой / со сдвигом |
| F9, F10, ⇧F12 | вставка, перезапись, в конец таймлайна |
| N | привязка |
| ⌘= ⌘- ⇧Z | масштаб, по размеру |
| ⌘Z ⇧⌘Z | отменить, вернуть |
| ⌘S ⇧⌘S ⌘O | сохранить, сохранить как, открыть проект |

## Как это устроено

```
src/
  domain/          чистая модель: время в кадрах, таймлайн, проект, пресеты, план рендера
  application/     редактор (команды, история, автосохранение), воспроизведение, порты
  engine/          браузерный движок: WebCodecs + Mediabunny, микшер звука, рендер в воркере
  infrastructure/  IndexedDB (сессия, ссылки на исходники, недавние), файлы проекта и видео
  ui/              интерфейс
```

Домен не знает про браузер. Движок подключён через порты (`src/application/ports.ts`), поэтому десктопная версия для Mac (Tauri + нативный кодек) встанет на место браузерного движка без изменений в монтаже.

Почему рендер точный:

- позиции и длительности хранятся целыми кадрами, секунды появляются только на границе с декодером;
- превью и рендер выбирают кадр исходника одной функцией (`videoSourceTime`), поэтому что видно на таймлайне, то и попадёт в файл;
- звук любых исходников (44.1/48 кГц) ресемплируется в 48 кГц и сводится микшером с точностью до отсчёта;
- задержка AAC-кодера измеряется и компенсируется (edit list), звук не отстаёт от видео;
- рендер идёт в отдельном потоке; при ошибке или отмене недописанный файл не сохраняется.

## Разработка

```bash
npm install
npm run dev        # http://localhost:5190
npm test           # тесты домена и звука
npm run typecheck
```

Сквозная проверка рендера (в консоли страницы в режиме разработки):

```js
await (await __dev.renderCheck())()
```

Она генерирует тестовые видео с закодированным номером кадра и щелчками звука, собирает таймлайн с резами, пустотой и верхней дорожкой, рендерит и сверяет каждый кадр и синхронизацию звука.
